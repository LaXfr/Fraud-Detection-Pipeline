# 🌳 Git Strategy & Log

**Branching Strategy:** Main branch only (Rapid Prototyping).

## Commit Convention
- `feat:` New capability (e.g., `feat: add Python faker generator`)
- `fix:` Bug resolution (e.g., `fix: resolve Postgres JDBC connection timeout`)
- `infra:` Docker or config changes (e.g., `infra: add FastAPI port 8000 to docker-compose`)
- `refactor:` Code cleanup without logic change
