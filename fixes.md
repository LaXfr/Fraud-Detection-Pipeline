# 🔧 Fixes & Troubleshooting

| Error / Symptom | Component | Root Cause | Solution |
| :--- | :--- | :--- | :--- |
| *Example: Spark fails to read Kafka* | PySpark | Missing Kafka package jar | Added `--packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.3.0` to spark-submit |
| `java.io.FileNotFoundException: HADOOP_HOME and hadoop.home.dir are unset` | PySpark / Windows | Missing Windows native Hadoop binaries (`winutils.exe`, `hadoop.dll`) | Downloaded Hadoop 3.3.x binaries to `C:\hadoop\bin`, set `$env:HADOOP_HOME="C:\hadoop"`, and added programmatic path injection to top of `spark_processor.py`. |
| `java.lang.NoSuchMethodError: 'scala.collection.mutable.WrappedArray'` | PySpark / Scala | Scala version mismatch between default unpinned PySpark runtime and `spark-sql-kafka-0-10_2.12:3.5.0` | Strictly pinned `pyspark==3.5.0` in `requirements.txt` to align Scala 2.12 binary compatibility across PySpark and the Kafka connector. |
| `java.lang.UnsupportedOperationException: getSubject is not supported` | PySpark / Java Runtime (JDK 21+) | Windows environment/PATH overrides default to modern Java 21+ which removed Security Manager `Subject.getSubject` | Hardcoded `os.environ["JAVA_HOME"]` and prepended `bin` to `os.environ["PATH"]` dynamically at top of `spark_processor.py` using `glob.glob` to lock PySpark to JDK 17. |
| `RuntimeError: reentrant call inside <_io.BufferedReader>` | PySpark / Py4J (Python 3.13) | Calling `df.isEmpty()` inside `foreachBatch` causes reentrant socket read on Py4J's gateway stream | Removed `df.isEmpty()`; allowed Spark's JDBC writer to handle empty micro-batches directly. |
| `PSQLException: FATAL: password authentication failed for user "admin"` | PostgreSQL / Port 5432 Collision & Credential Mismatch | Native Windows service `postgresql-x64-18` was intercepting port 5432 while `spark_processor.py` was hardcoded to `barbarian_1` against Docker's `password` credential. | Stopped native Windows service, updated `spark_processor.py` to `password`, created `postgres` superuser inside Docker, and ran `ALTER ROLE admin WITH PASSWORD 'password';` to lock credentials. |
| `IllegalStateException: SparkContext has been shutdown` (with reentrant BufferedReader error) | PySpark / Signal Handling (Python 3.13) | Interrupting PySpark (`Ctrl+C` or taskkill) during a streaming batch causes PySpark's SIGINT handler to re-enter the socket stream while cancelling jobs | Wrapped `spark.streams.awaitAnyTermination()` in `try...except KeyboardInterrupt` for clean query termination, and added real-time console status logs so processing activity is visible. |
| `error: uv trampoline failed to canonicalize script path` | FastAPI / Uvicorn (uv virtualenv) | `uv`'s launcher shim `.exe` fails Windows path canonicalization across NTFS directory junctions (`dev-fs` vs `dev(fs)`), and command was run inside `frontend/` where `main.py` does not reside | Navigate back to project root (`cd ..`) and execute using Python module syntax: `python -m uvicorn main:app --reload --port 8000`. |
